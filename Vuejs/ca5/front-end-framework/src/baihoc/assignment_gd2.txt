Đề: Xây Dựng Ứng Dụng Quản Lý Sinh Viên (Student Management)
YÊU CẦU

Xây dựng một ứng dụng quản lý sinh viên sử dụng:

Vue 3 (Composition API)
Vue Router
Axios (call API JSON Server)
KIẾN THỨC ÁP DỤNG

Sinh viên bắt buộc dùng:

Component
Props / Emit
v-model, v-for, v-if
Vue Router
Axios (CRUD API)

CẤU TRÚC DỮ LIỆU

Mỗi sinh viên có:

{
  "id": "random",
  "name": "Nguyễn Văn A",
  "age": 20,
  "email": "a@gmail.com",
  "avatar": "https://..."
}
API
GET     /students
GET     /students/:id
POST    /students
PATCH   /students/:id
DELETE  /students/:id
